# Security policy

## Reporting a vulnerability

If you would like to report a public issue (for example, one with a released
CVE number), please report it using the
[github issue tracker](https://github.com/koenkooi/mackas/issues).

How mackas is built to keep security risk low — dependency surface, isolation,
supply-chain integrity, and how that relates to the EU Cyber Resilience Act — is
documented in [docs/security.md](docs/security.md).
